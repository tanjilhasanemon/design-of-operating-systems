# Design of Operating Systems - Class Performances

This repository contains all Class Performance (CP) tasks for the **Design of Operating Systems** course.

It is structured to ensure that all tasks, scripts, and concepts are well-documented and can be executed across different environments (Linux, Windows).

## Repository Structure

Each CP task is contained within its own folder, following a standard structure:
- `src/`: Contains all source code and executable scripts.
- `CONCEPTS.md`: A clear, easy-to-understand explanation of the core OS theory and concepts for that specific task.
- `RUN_GUIDE.md`: A step-by-step guide with exact commands and a line-by-line breakdown on how to compile and run the programs.
